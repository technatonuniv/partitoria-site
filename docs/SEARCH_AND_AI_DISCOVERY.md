## Подключение поиска владельцем

1. В Google Search Console добавить ресурс типа **Domain** со значением `partitoria.app`. Выбрать TXT и скопировать **полное** выданное значение `google-site-verification=…`. У регистратора добавить отдельную запись TXT для корня зоны (поле имени обычно `@` или пустое). Сохранить существующие записи. После появления записи в DNS нажать **Verify**. Точное значение выдаётся в аккаунте. [Проверка прав Google](https://support.google.com/webmasters/answer/9008080?hl=en)
2. В Bing Webmaster Tools выбрать **Import from Google Search Console**, отметить только подтверждённый `partitoria.app` и проверить предложенные сайту права. Альтернатива без подключения Google — добавить `https://partitoria.app/` вручную и выполнить показанный Bing DNS challenge с **точными именем и значением**. После подтверждения оставить запись доступной для повторной проверки. [Импорт и методы проверки Bing](https://blogs.bing.com/webmaster/2019/9/Import-sites-from-Search-Console-to-Bing-Webmaster-Tools/)
3. После одобренной публикации открыть Sitemaps в обеих панелях. Указать `https://partitoria.app/sitemap.xml`, если карта ещё не импортирована. Зафиксировать дату чтения и состояние обработки. В URL Inspection проверить новые URL по списку в начале отчёта, включая `/facts` и `/en/facts`: доступность, выбранный canonical и состояние индексации. На коротком русском адресе проверить также отрендеренный язык из-за действующего автовыбора. Повторить через 7 и 28 дней. Статус «обнаружен» или «запрошена индексация» записывать отдельно от «проиндексирован».
4. В Google открыть **Performance → Generative AI (Search)**. Отчёт появляется при достаточном числе показов. Отдельную разбивку использовать для показов ссылок в AI Overviews и AI Mode по страницам, стране, устройству и дате. Общие клики и запросы брать из Search results. [Справка по генеративному поиску](https://support.google.com/webmasters/answer/16984139?hl=en) · [Общие результаты поиска](https://support.google.com/webmasters/answer/7576553/performance-report-search)
5. Публичный ключ и [скрипт IndexNow](../scripts/indexnow.mjs) готовы. Локальная команда `npm run indexnow -- /en/facts /en/answers/bluetooth-page-turner` печатает JSON. Для этого выпуска 44 адреса с подтверждённым изменением содержания выбираются из карты по дате `2026-11-25`. Список передаётся как аргументы либо через `--file changed-urls.txt` (UTF-8, по одному URL в строке). Только после одобренной выкладки и отдельного разрешения добавить `--submit`. Скрипт проверяет опубликованный ключ перед отправкой. HTTP 200 означает получение списка, 202 — получение с ожидающей проверкой ключа. [Протокол IndexNow](https://www.indexnow.org/documentation)
