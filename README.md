# Partitoria website

Official public website for **Partitoria**, an offline-first personal sheet-music library for Android.

The site is intentionally static: it has no accounts, cookies, analytics, advertising, forms, or runtime third-party assets. It includes the public privacy policy, support details, copyright notice, terms of use, and the current external-source policy.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The static export is written to `dist/client` and published with GitHub Pages.
